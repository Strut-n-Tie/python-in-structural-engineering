# Shortcuts

Press `Esc` to activate **command** mode. Press `Enter` to activate **edit** mode.

**Edit** mode shortcuts:
* `Crtl` + `Enter` - run the current cell, do not move the cursor
* `Shift` + `Enter` - run the current cell, move the cursor to the next cell
* `Alt` + `Enter` - run the current cell, insert a new cell below and move the cursor to it

**Command** mode shortcuts:
* `Up`/`Down` arrow keys - move cursor to the cell above/below
* `A`/`B` - insert a new cell above/below the current cell
* `Y` - change the cell mode to Code
* `M` - change the cell mode to Markdown
* `D` + `D` - delete the active cell
* `Z` - undo cell deletion
